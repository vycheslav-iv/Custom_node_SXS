# SXS — сцена для KonstCharacter

Нода собирает **бриф сцены** из описаний персонажей `KonstCharacter` и отдаёт
два текста:

- **`LLM PROMPT`** — инструкция внешней LLM: система, бриф в JSON, что ей
  разрешено выбрать, правила.
- **`MODEL PROMPT`** — готовый промпт для модели изображений/видео. Все
  делегированные LLM поля уже заменены конкретными значениями.

Нода **не вызывает LLM** и не генерирует картинку. Она детерминированно
превращает виджеты и входы в текст; LLM (если нужна) работает отдельно и
возвращает результат в модель.

## Установка

Папка `SXS` уже лежит в `ComfyUI/custom_nodes/`. После копирования или
обновления перезапустите ComfyUI и обновите страницу (`Ctrl+F5`).

Категория в меню: **`My_custom_nodes/SXS`** → **`SXS Scene Prompt`**.

## Входы

### Обязательные поля

| Группа | Поля |
|---|---|
| Настройка | `seed`, `Язык_меню`, `Язык_промпта`, `Управление` |
| Персонажи | `Девушки`, `Парни`, `Распределение`, `Авто_пары`, `Кто_с_кем`, `Фокус_на`, `Политика_отсутствующего`, `Пол_1…Пол_6` |
| Сцена | `Пресет_сцены`, `Тип`, `Тип_выбирает_LLM`, `Этап_сцены`, `Куда_кончает`, `Тип_группа_*`, `Совместимость`, `Взаимодействия`, `Эмоции`, `Темп`, `Одежда` |
| Поза | `Позы_выбирает_LLM`, `Позы_группа_*`, `Поза`, `Взгляд`, `Кто_сверху`, `Положение_камеры` |
| Камера | `Камера_выбирает_LLM`, `Ракурс`, `План`, `Фокус`, `Ракурсы_вкл`, `Планы_вкл`, `Фокусы_вкл`, `Уровень_камеры`, `POV`, `Композиция`, `Кроп`, `Куда_смотрит_камера`, `Зум` |
| Окружение | `Окружение_выбирает_LLM`, `Фон`, `Освещение`, `Время_суток`, `Атмосфера`, `Сеттинг`, `Фоны_вкл`, `Свет_вкл`, `Время_вкл`, `Атмосфера_вкл`, `Сеттинг_вкл` |
| Стиль | `Формат_промпта`, `Модель`, `Стиль`, `Качество`, `Quality_tokens` |
| LLM | `Всё_выбирает_LLM`, `Свобода_LLM`, `Запреты`, `Явные_термины` |

### Необязательные входы

- **`config`** — строка JSON от `KonstCharacterConfig.generate()`. Оттуда
  берутся `master_seed`, `age`, `nationality`, `personality`, `preamble` и пол.
- **`char_1…char_6`** — строки от `KonstCharacterMerge.prompt`, то есть
  готовые описания внешности. Пустой/неподключённый вход означает отсутствие
  персонажа.

Минимальная схема:

```
KonstCharacterConfig.generate → SXS.config
KonstCharacterMerge.prompt (1..6) → SXS.char_1..char_6
SXS.LLM PROMPT → внешняя LLM
SXS.MODEL PROMPT → промпт модели
```

## Выходы

| Выход | Что это |
|---|---|
| `LLM PROMPT` | Блоки `[SYSTEM]`, `[BRIEF]`, `[ALLOWED]`, `[RULES]`. |
| `MODEL PROMPT` | Готовый промпт без делегирования; `llm_choice` заменён значением. |
| `WARN` | Предупреждения (конфликт типа, нераспознанный пол, откат значения). Пусто = ошибок нет. |
| `SEED` | Фактический seed (если виджет `seed = 0`, берётся `master_seed` из config). |
| `CONFIG` | JSON-бриф без `warnings`; годится для отладки и повторного запуска. |

## Как это работает

1. **config** разбирается как JSON. Ошибка разбора не роняет ноду: поля
   просто не заполняются, в `WARN` попадает сообщение.
2. **Персонажи** берутся из `char_1…char_6`. `Девушки`/`Парни` = `auto`
   считает по описаниям и явным `Пол_N`; `0…3` задаёт количество; `random`
   выбирает допустимое.
3. **Пол** определяется по `Пол_N` → тексту описания. Не распознан —
   `WARN`, при `Политика_отсутствующего = invent` персонаж может быть
   досочинён, иначе роль свободного слота добирается автоматически.
4. **Тип сцены** проверяется по матрице `TYPE_RULES` (какие участники и
   аксессуары нужны). `strict` исключает невозможное; ручной конфликт даёт
   `WARN` и откат к безопасному значению.
5. **Этап сцены** (`Этап_сцены`) добавляет в промпт момент действия:
   начало, первое проникновение, середину или финал. `auto` не упоминает
   этап, `random` выбирает допустимый этап по типу сцены. Для `oral`,
   `fingering`, `facesitting`, `bukkake` и сольных типов проникновение
   недоступно.
6. **Куда кончает** (`Куда_кончает`) работает только при
   `Этап_сцены = finish`: список фильтруется типом сцены и участниками
   (`creampie` → только внутрь, `oral` → рот/лицо/грудь/тело/наружу,
   без мужчины → не указано). Невозможное явное значение даёт `WARN` и
   откат к допустимому.
7. **Пресет** заполняет только нейтральные поля, явные значения важнее.
8. **Делегирование** (`*_выбирает_LLM`) оставляет в `BRIEF` маркер
   `{"mode":"llm_choice","allowed":[...]}`. `MODEL PROMPT` всегда
   конкретизирует его через seed.
9. **Случайность** — `MD5(seed + key)`: один seed даёт один и тот же бриф.
   Меняете seed — меняется выбор в делегированных полях.

## Делегирование LLM

- `Позы_выбирает_LLM = ON` (по умолчанию) — LLM выбирает позу/взгляд из
  разрешённых списков. Для готового промпта без LLM выключите его.
- `Тип_выбирает_LLM`, `Камера_выбирает_LLM`, `Окружение_выбирает_LLM` —
  то же для своих групп.
- `Всё_выбирает_LLM = ON` включает все четыре и блокирует подчинённые
  переключатели.
- `Свобода_LLM`: `strict` — только из `[ALLOWED]`; `from_lists` — из списков
  ноды; `free` — шире, но в рамках `[RULES]`.
- `Запреты` — дополнительный текст ограничений. `Явные_термины` разрешает
  прямые анатомические термины вместо эвфемизмов.

## Язык

- `Язык_меню = auto` следует языку ComfyUI (`Comfy.Locale`); `ru`/`en`
  принудительно включают русский/английский интерфейс ноды.
- `Язык_промпта` задаёт язык `LLM PROMPT` и `MODEL PROMPT` независимо от
  интерфейса.
- Язык интерфейса меняется на лету, без перезапуска. Значения combo
  (например `classic`, `soft`) не переводятся — переводится только подпись.

## Ограничения

- Нода **не** содержит модель и не делает инференс. Для вызова LLM нужен
  отдельный узел/сервис.
- Сцена описывает взрослых персонажей (18+); проверка несовершеннолетних
  зашита в `[SYSTEM]` и `[RULES]`.
- Внешность берётся из `char_N` как текст. Если вы поменяли персонажа в
  `KonstCharacter`, перезапустите граф, чтобы SXS получил новый текст.
